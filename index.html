SuperFedora 🛸

Curated keyboard-driven Fedora workstation, in one command.

Install

  1. Install Fedora from the Everything netinstall ISO. Under Software Selection pick Minimal Install, and create a user with administrator rights. Keep the default Btrfs layout to enable snapshot rollbacks.
  2. Log in on the console and run: 
    curl -fsSL https://superfedora.github.io/install.sh | bash
  3. Reboot. Log in at the tuigreet screen and Hyprland starts automatically. Super + F1 lists every keybinding.

SuperFedora checks every component first and installs only what is missing, so it's safe to run again at any time. It also works on an existing Fedora Workstation or Server.

Commands

CommandWhat it does
superfedora statusChecks every component: ✓ present, ✗ missing. Changes nothing
superfedora installInstalls whatever is missing
superfedora install --dry-runShows what install would do
superfedora install --only desktop,dotfilesRuns selected modules (by name or number); --skip works the same way
superfedora updateFetches the latest release, then runs install
superfedora dotfiles [--check]Re-deploys the desktop configs, or lists local edits
superfedora rollbackReverts system files to the Btrfs snapshot taken before the first install

The install log is ~/.config/superfedora/install.log. Config files that were replaced are backed up in ~/.config/superfedora/backups/.
