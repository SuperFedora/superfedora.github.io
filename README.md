# SuperFedora Web Portal & CDN 🛸

The official 16-bit web portal, documentation hub, and bootstrap CDN for **SuperFedora** — the curated, keyboard-driven Fedora workstation.

* **Live Site:** [https://superfedora.github.io](https://superfedora.github.io/)
* **One-Line Bootstrap:** `curl -fsSL https://superfedora.github.io/install.sh | bash`
* **Core Workstation Monorepo:** [SuperFedora/superfedora](https://github.com/SuperFedora/superfedora)

Features interactive 16-bit SNES aesthetics, component breakdown, Pop!_OS COSMIC keybinding matrix, and installer guides.
